A make.fun bounty entry for [The Robot Vacuum's Best Excuse](https://make.fun/c/u-golden-heron-44-the-robot-vacuum-s-best-excuse-53412214): the funniest one-line excuse a robot vacuum gives for missing a spot, 140 characters or fewer.

## How it works

`main.py` writes a single deterministic line to `MAKEFUN_OUTPUT_DIR/entry.txt` (falling back to `.` if unset). No network, no model, no clock, no environment dependence — the same line every run.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=./out python3 main.py
cat out/entry.txt
```
